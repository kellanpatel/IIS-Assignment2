# IIS-Assignment2
Repository link: https://github.com/kellanpatel/IIS-Assignment2/tree/main

Project status and technology
- Developed: A PowerPoint walkthrough simulating a phone recommendation interface. PowerPoint displays the screens and hyperlinks between them connect preferences, shortlists, phone details and confirmation screens.
- Simulated: The phone rankings, explanations and warnings are written in advance and do not change. Each confirmation screen is generated by duplicating the first one and changing the text to match the chosen phone. 
- Unfinished: Budget and main use are fixed options. Phone specifications are not complete, only some features are included. Some detail screens do not reflect a change in priority. 
- Planned: To add more phones, more specifications, and more detail screens. Main use and budget will be editable. Navigation will be improved to allow users to go back and change their preferences without losing their shortlist.



How to run:
- Open the PowerPoint file in Microsoft PowerPoint or a compatible viewer.
- Start the slideshow from the first slide and click the on-screen buttons to navigate through the interface. You'll know if it is a button if the cursor changes to a hand when hovering over it. 



Development record
- I narrowed Assignment 1’s proposed comparison of explanation styles to one approach. Keeping the £500 budget and everyday use fixed made the effect of changing priority easier to see.
- I duplicated the Phone A confirmation screen and changed the copies for B and C so shoppers could verify their final choice. I followed each selection route and checked that the phone named on the last slide matched the one chosen.
- I duplicated the "Edit preferences" screen so that it visually matched the chosen preference. I also added functionality ensuring the user confirms their choice before the shortlist changes, to avoid confusion.
